# Linear Algebra Dashboard

An interactive dashboard developed as a Final Linear Algebra Project.

## 📌 About the Project
This project provides an interactive environment for exploring and performing Linear Algebra operations through a user-friendly dashboard.

## ✨ Features
- Interactive Linear Algebra operations
- Mathematical calculations and visualizations
- User-friendly dashboard interface
- PDF report generation
- Automated testing

## 🛠 Technologies
- Python
- Streamlit
- NumPy
- SciPy
- Matplotlib

## 🚀 Installation & Usage

1. Clone the repository:

```bash
git clone https://github.com/pardis-eslami/Linear-Algebra.git
```

2. Enter the project directory:

```bash
cd Linear-Algebra/linear_algebra_dashboard_v3
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
streamlit run app.py
```
