# آزمایشگاه جبر خطی

## اجرا

از داخل پوشهٔ پروژه این سه دستور را اجرا کنید. نصب مرورگر بدون رابط گرافیکی برای ساخت PDF فقط بار اول لازم است.

```bash
python -m pip install -r requirements.txt
python -m playwright install chromium --only-shell
python -m streamlit run app.py
```

در ویندوز، اگر دستور `python` شناخته نشد، از `py` استفاده کنید. اگر Chromium از قبل روی سرور نصب شده، می‌توانید مسیر اجرایی آن را در متغیر محیطی `LINEAR_ALGEBRA_CHROMIUM` بگذارید.

## استفاده

- از بخش عملیات، دترمینان، ضرب، فرم پلکانی، فرم پلکانی کاهش‌یافته یا وارون ماتریس را انتخاب کنید.
- ابعاد و عددها را وارد کنید و «محاسبه» را بزنید. برای تغییر یک درایه، همان خانه را ویرایش و دوباره محاسبه کنید. در ماتریسی که وارد شده، هر خانهٔ خالی صفر حساب می‌شود.
- در ضرب، تعداد سطرهای B از ستون‌های A و تعداد ستون‌های B از سطرهای A تعیین می‌شود. دو فیلد B جدا و فقط‌خواندنی‌اند. خود درایه‌های B قابل ویرایش‌اند.
- بعد از محاسبه می‌توانید همهٔ مراحل شماره‌دار را باز کنید یا کل راه‌حل را به‌صورت PDF در اندازهٔ A4 دانلود کنید.
- نمایش نتیجه حداکثر سه رقم اعشار دارد. محاسبه با مقدار دقیق انجام می‌شود. مقدارهای بسیار کوچکِ غیرصفر با نمایش علمی دیده می‌شوند. گزینهٔ «ارقام فارسی» نمایش را فارسی می‌کند.
- سه آیکون بالای سمت چپ، ظاهر مطابق دستگاه، روشن و تاریک را انتخاب می‌کنند.
